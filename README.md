## BIT225 Assignment 2

BlueLib Catalogue is a responsive and interactive library catalogue website created for BlueCrest College.

The website allows students to browse books, search for books by title, filter books by category, add new books, and borrow available books.

## Features

- Responsive library catalogue
- Book cards displaying:
    - Title
    - Author
    - Category
    - Copies available
- Search books by title as the user types
- Filter books by category
- Add new books using the Add Book form
- Borrow books and reduce available copies
- Displays "Out of stock" when copies reach zero
- Disables the Borrow button when a book is out of stock
- Responsive layout for desktop, tablet, and mobile screens
- Hover effects on cards and buttons

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or external libraries were used.
